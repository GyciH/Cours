# Bibliothèque de cours

Application personnelle, installable sur téléphone et utilisable hors ligne, pour lire les cours de la bibliothèque (Rhino, Grasshopper, C#, géométrie, web, réseau…), faire leurs QCM et suivre une révision espacée.

Ouvrir la page GitHub Pages dans Chrome, puis menu ⋮ → « Installer l'application ». Au premier lancement, tout est mis en cache ; ensuite l'app marche sans réseau. La progression reste sur le téléphone (export/import dans l'onglet Progrès).

Fichiers générés : ne pas modifier à la main.
