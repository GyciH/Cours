Le concept

Une application web installable

Magpie Web s'ouvre dans un navigateur, mais un apprenant peut aussi l'installer sur l'écran d'accueil de son téléphone ou de sa tablette. Lancée de là, elle prend tout l'écran, sans barre d'adresse, en paysage. Un fichier de description, quelques balises, et une interface qui sait qu'on la touche au doigt.

45 min de lecture et de QCM Prérequis · 29, 31, 32 et 35 Exemples · public/manifest.webmanifest, index.html, graphEditor.jsx, styles.css (Magpie web)

L'idée en une phrase

Le manifeste dit au système comment présenter l'application une fois installée ; les règles @media (pointer: coarse) adaptent l'interface au doigt ; le reste corrige ce qu'un téléphone a de particulier : l'encoche, la barre d'adresse, le portrait.

L'analogie

Un raccourci de bureau qui ouvrirait une fenêtre sur mesure. Le programme reste le même site, au même endroit ; seule la façon de l'ouvrir et de l'habiller change.

À la fin, tu sais

  1. lire un manifeste d'application web ;
  2. distinguer ce qu'Android et iOS lisent chacun ;
  3. adapter une interface au doigt avec pointer: coarse ;
  4. garder le contenu dans la zone sûre de l'écran.
À retenir Installée, Magpie reste un site : elle n'a pas de service worker, donc rien ne fonctionne hors ligne. L'icône ouvre le même serveur, la même adresse ; mettre en ligne une nouvelle version (cours 35) met à jour toutes les applications installées à leur prochaine ouverture.

Schéma 1 · Le manifeste et les balises

Dix-huit lignes pour Android, quatre balises pour iOS

index.html désigne le manifeste par une balise <link rel="manifest">. Chrome sur Android y lit le nom, les icônes et l'affichage voulu ; Safari sur iPhone préfère ses propres balises apple-…, posées juste à côté.

public/manifest.webmanifest · 6–16, extraits"start_url": "/", "scope": "/", "display": "fullscreen", "display_override": ["fullscreen", "standalone"], "orientation": "landscape", "background_color": "#dcdad2", "theme_color": "#20262a", "icons": [ …192, …512, { "src": "/app-icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }

Plein écran, sinon sans barre

display_override donne un ordre de préférence : le système prend le premier mode qu'il sait faire. fullscreen masque aussi la barre d'état ; standalone garde la barre d'état mais retire celle du navigateur.

Une icône qu'on peut rogner

Android découpe les icônes en cercle, en carré arrondi ou en goutte, selon le téléphone. L'icône maskable garde le dessin au centre, avec une marge que la découpe peut manger sans toucher la pie. iOS prend apple-touch-icon.png (index.html, ligne 14).

Piège courant Oublier le serveur. En production, c'est compute-proxy.mjs qui sert les fichiers, avec un type par extension ; un fichier inconnu part en application/octet-stream (ligne 510). Le commit qui rend Magpie installable a donc dû ajouter .webmanifest à MIME_TYPES (ligne 57).

Schéma 2 · Le doigt n'est pas une souris

pointer: coarse

Une souris pointe au pixel près, survole, double-clique ; un doigt couvre une zone large et n'a ni survol ni touche Suppr. CSS sait dire lequel pilote l'écran : pointer: fine pour une souris ou un stylet, pointer: coarse pour un doigt.

src/styles.css · 1446–1476, extraits/* Barre d'outils tactile : ajouter (au lieu du double-clic sur le fond) et supprimer (au lieu de la touche Suppr). Invisible à la souris. */ .magpie-touchbar { position: absolute; right: 10px; bottom: 12px; display: none; … } .magpie-touchbar button { min-height: 44px; … } @media (pointer: coarse) { .magpie-touchbar { display: flex; } }

Poser d'un toucher

Comme dans Grasshopper, un composant choisi dans le ruban attend qu'on désigne sa place : un toucher sur le canvas le pose centré sous le doigt (graphEditor.jsx, lignes 378–384). Les fils s'accrochent à 28 px d'une poignée (connectionRadius, ligne 405).

Le dernier bloc gagne

Plusieurs blocs @media (pointer: coarse) se suivent dans styles.css. À sélecteurs égaux, c'est le dernier écrit qui l'emporte : les boutons de la barre, réglés à 44 px ligne 1458, passent à 38 px ligne 1788, pour laisser la place au canvas.

Piège courant Un double-clic sur le fond du canvas ouvre la recherche rapide. Toucher deux fois vite un bouton posé sur le canvas l'ouvrirait aussi : le double-clic remonte jusqu'au fond. Chaque bouton l'arrête, onDoubleClick={(e) => e.stopPropagation()} (lignes 435, 446, 466).

Schéma 3 · L'écran du téléphone

Plein écran, paysage, zone sûre

Un téléphone tenu en portrait laisse au canvas une bande étroite ; installé ou en plein écran, il passe sous l'encoche. Magpie traite les deux, et ne fait pas la même chose sur Android et sur iPhone.

src/graphEditor.jsx · 354–365const toggleFullscreen = async () => { try { if (document.fullscreenElement) { await document.exitFullscreen(); return; } await document.documentElement.requestFullscreen({ navigationUI: "hide" }); await screen.orientation?.lock?.("landscape").catch(() => {}); } catch { // refusé par le navigateur : rien à faire, la page reste utilisable } };

La zone sûre

viewport-fit=cover (index.html, ligne 5) étend la page sous l'encoche et la barre d'état. Le contenu s'en écarte de env(safe-area-inset-…) de chaque côté (styles.css, ligne 1683), une marge que le téléphone fournit.

La vraie hauteur

Sur mobile, 100vh vaut la hauteur de la fenêtre barre d'adresse masquée : quand la barre est là, la page déborde dessous. 100dvh suit la hauteur réellement visible ; Magpie l'utilise là où le navigateur la connaît (@supports, lignes 1362–1366).

Piège courant Verrouiller le paysage avant d'être en plein écran : la plupart des navigateurs refusent. D'où l'ordre, requestFullscreen puis orientation.lock, et le .catch() qui avale un refus. Sur iPhone, document.fullscreenEnabled est faux : le bouton n'apparaît pas (ligne 442).

Glossaire

Manifeste
Le fichier JSON qui décrit une application web installable.
Service worker
Un script d'arrière-plan qui peut servir des pages sans réseau ; Magpie n'en a pas.
Zone sûre
La partie de l'écran que ni l'encoche ni les barres système ne couvrent.
dvh
Un centième de la hauteur réellement visible de la fenêtre.
Cascade
La règle CSS qui départage deux déclarations ; à égalité, la dernière gagne.
