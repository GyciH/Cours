Le concept

L'éditeur d'exercices

Pour créer un exercice Magpie, l'auteur ne remplit pas un fichier : il résout l'exercice dans Grasshopper, branche sa solution sur l'éditeur, et dépose sous lui les composants que l'apprenant trouvera au départ. Un clic sur Enregistrer, et tout part dans un fichier JSON.

50 min de lecture et de QCM Prérequis · 12, 20, 21 et 37 Exemples · Admin/MagpieExerciseEditor.cs, Admin/ModesCorrection.cs, Core/ValidationMode.cs (Magpie)

L'idée en une phrase

Un seul composant tient tout l'exercice : les champs saisis dans sa capsule, la réponse attendue sur son unique entrée, et une zone en pointillés dont les composants deviennent le graphe de départ de l'apprenant.

L'analogie

Un professeur qui prépare une feuille d'exercice en la faisant lui-même : il écrit l'énoncé en haut, garde son corrigé de côté, et laisse sur la feuille les premières lignes à compléter.

À la fin, tu sais

  1. choisir un mode de correction et sa tolérance ;
  2. dire quand un composant entre dans la zone de départ ;
  3. suivre les contrôles faits avant d'enregistrer ;
  4. expliquer l'état « Enregistré » et son empreinte.
À retenir L'Id de l'exercice est aussi son nom de fichier : Exercises\<Id>.json dans le dossier de travail (MagpieRepository.cs, lignes 90–95). C'est pourquoi l'éditeur refuse un Id vide ou qui contient un caractère interdit dans un nom de fichier (ligne 585).

Schéma 1 · Les modes de correction

Sept façons de comparer

Le mode dit comment la réponse de l'apprenant sera comparée à celle de l'auteur. Il dit aussi ce que la prise « Réponse attendue » doit recevoir, et si la case Tolérance a un sens.

Admin/ModesCorrection.cs · 45–52public static bool AvecTolerance(ValidationMode mode) => mode == ValidationMode.NumericTolerance || mode == ValidationMode.GeometryTolerance; public static bool ToleranceObligatoire(ValidationMode mode) => mode == ValidationMode.NumericTolerance; public static bool EstTexte(ValidationMode mode) => mode == ValidationMode.ExactOrderedListText || mode == ValidationMode.SetEqualityText;

Deux noms par mode

Sur le canvas, l'auteur lit « Liste ordonnée (nombres) » ; dans le JSON, c'est ExactOrderedList. Les libellés vivent dans ModesCorrection (lignes 28–37) ; les noms techniques ne se lisent jamais sur le canvas, car ils sont un format de fichier.

Un arbre, en mode liste seulement

Une réponse attendue à plusieurs branches est un arbre : sa forme sera vérifiée aussi (issue #10). Seuls les cinq modes de liste savent comparer branche par branche ; avec un autre mode, l'éditeur refuse d'enregistrer (ligne 615).

Piège courant Ajouter un mode au milieu de l'énumération. Les vieux exercices portent leur mode en entier ("Mode": 0), lu comme une position : insérer un membre décale tous les suivants et change en silence le mode de ces fichiers. Un nouveau mode s'ajoute à la fin (ValidationMode.cs, lignes 12–15).

Schéma 2 · La zone de départ

C'est le centre qui décide

Sous la capsule, la zone en pointillés tient lieu de groupe. Un composant dont le centre tombe dedans en devient membre ; la zone grandit pour l'entourer, avec 12 unités de marge, et suit l'éditeur quand on le déplace.

Admin/MagpieExerciseEditor.cs · 502–514var ids = new HashSet<Guid>(deplaces.Select(o => o.InstanceGuid)); var zone = Attrs.ZoneSans(ids); … foreach (var obj in deplaces) { if (!Adherable(obj, this)) continue; if (zone.Contains(Centre(obj))) change |= AjouterMembre(obj); else change |= _membres.Remove(obj.InstanceGuid); } if (change) ApresChangementDeZone();

Lu à la fin du geste

À l'enfoncement du bouton, l'éditeur note où est chaque objet (ligne 468). Au relâchement, il attend que Grasshopper ait fini (BeginInvoke, ligne 480), puis ne réexamine que les objets qui ont bougé, dans la zone sans eux : un membre ne se garde pas dedans parce qu'il l'a lui-même agrandie.

Une liste, pas un groupe

Les membres sont une liste d'InstanceGuid que l'éditeur garde (ligne 75), pas un GH_Group qu'on pourrait vider ou supprimer par accident. Un éditeur collé abandonne les membres déjà revendiqués par l'original (ligne 396).

Piège courant Déplacer l'éditeur avec un composant sélectionné en même temps. C'est un déplacement d'ensemble : la zone suit, et rien n'y entre ni n'en sort (lignes 494–500). Pour faire entrer un composant, il faut le glisser seul jusqu'à ce que son centre soit dans la zone.

Schéma 3 · Enregistrer

Valider, demander, écrire, retenir

Enregistrer ne se contente pas d'écrire. L'éditeur vérifie d'abord que l'exercice est jouable, demande avant d'écraser, puis retient une empreinte de ce qu'il vient d'écrire pour savoir, plus tard, si quelque chose a changé.

Admin/MagpieExerciseEditor.cs · 289–296, 319–325private string CalculerSignature() { var sb = new StringBuilder(); sb.Append(Id).Append('\u001f').Append(Titre).Append('\u001f').Append(Consigne).Append('\u001f') … … using (var sha = SHA256.Create()) return Convert.ToBase64String(sha.ComputeHash(Encoding.UTF8.GetBytes(sb.ToString()))); } private static readonly Regex RetirerPositions = new Regex("<item name=\"(Bounds|Pivot)\"[\\s\\S]*?</item>", …);

Deux empreintes, pas le fichier

Le bouton affiche « Enregistré » tant que l'empreinte du contenu actuel égale celle prise à l'enregistrement. On ne compare pas au fichier : le graphe de départ y est une archive Grasshopper, rien ne garantit qu'elle se reproduise à l'octet près (lignes 281–284).

Déplacer n'est pas modifier

Avant le hachage, les positions et les cadres des composants de départ sont retirés de leur archive (RetirerPositions). Ranger la zone ne fait donc pas repasser le bouton à « Enregistrer » ; changer une valeur, si.

Piège courant Écraser un autre exercice en réutilisant son Id. L'éditeur le demande, et le bouton par défaut est « Non » (Button2, ligne 572). Même garde-fou si la zone est vide alors que l'exercice existant avait des composants de départ (lignes 543–552).

Glossaire

Mode de correction
La règle qui compare la réponse de l'apprenant à celle de l'auteur.
Réponse attendue
La solution de référence, branchée par l'auteur sur l'éditeur.
Graphe de départ
Les composants posés d'office sur le canvas de l'apprenant.
Empreinte (hash)
Un résumé court d'un contenu, qui change dès que le contenu change.
Garde-fou
Une question posée avant une action qu'on ne pourrait pas défaire.
