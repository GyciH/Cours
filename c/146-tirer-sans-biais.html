Le concept

Tirer sans biais

Un bon générateur ne suffit pas : il faut encore transformer ses nombres en indice, en ordre, en point. Chaque transformation peut favoriser certains résultats sans que rien ne se voie à l'œil. Une borne mal placée, un mélange trop naïf, un rayon tiré tout droit, et le hasard penche.

45 min de lecture et de QCM Prérequis · 137, 145 Exemples · Cuttlefish

L'idée en une phrase

Un tirage est sans biais quand chaque résultat possible est atteint par autant de chemins ; tout le travail consiste à compter ces chemins.

L'analogie

Un dé dont une face est un peu plus grande : il roule bien, il a l'air juste, et pourtant sur mille lancers, l'écart finit par apparaître.

À la fin, tu sais

  1. placer les bornes de Next ;
  2. mélanger avec Fisher-Yates ;
  3. tirer un point uniforme dans une forme ;
  4. éviter le biais du reste.
À retenir Un biais ne se voit pas sur un tirage : il se mesure sur des milliers. Compte les fréquences avant de faire confiance à une méthode.

Schéma 1 · Mélanger

Six ordres, six chances égales

Mélanger, c'est tirer une permutation. Quatre méthodes courantes ont mélangé trois lettres 600 000 fois ; on a compté chaque ordre obtenu.

Exemple autonome · C#, Fisher-Yatesfor (int n = liste.Count - 1; n > 0; n--) { int k = rand.Next(n + 1); // 0 à n : la case elle-même comprise (liste[k], liste[n]) = (liste[n], liste[k]); }

Pourquoi OrderBy marche

Trier selon une clé tirée une fois par élément est juste, aux égalités de clés près, rarissimes avec des entiers de 31 bits. Mais c'est un tri : n log n au lieu de n.

Pourquoi le comparateur casse

Un comparateur qui répond au hasard n'est pas un ordre (cours 137). Le tri en tire des conclusions fausses, et .NET le détecte parfois : 235 exceptions sur 20 000 (mesuré).

Piège courant Écrire k = rand.Next(liste.Count) dans la boucle de mélange. Le code est presque identique à Fisher-Yates, mais trois ordres sortaient à 18,5 % et trois à 14,8 % (mesuré).

Schéma 2 · Un point dans une forme

Corriger par l'aire

Tirer un point au hasard dans un disque ou un triangle passe par des paramètres, un rayon, des coefficients. Les tirer uniformément ne répartit pas les points uniformément.

Exemple autonome · C#, un point uniforme dans un disque et dans un triangledouble r = R * Math.Sqrt(rand.NextDouble()), a = 2 * Math.PI * rand.NextDouble(); // disque double u = rand.NextDouble(), v = rand.NextDouble(); if (u + v > 1) { u = 1 - u; v = 1 - v; } var p = A + u * (B - A) + v * (C - A); // triangle

D'où vient la racine

L'aire à moins de r du centre croît comme r². Pour que chaque anneau reçoive des points selon sa surface, on tire r² uniformément, donc r comme la racine d'un tirage.

Le rejet, toujours juste

Tirer dans le rectangle englobant et rejeter ce qui tombe dehors : uniforme pour toute forme, au prix des essais perdus, 21 % pour un disque (déduit : 1 − π/4).

Piège courant Normaliser trois nombres au hasard pour obtenir des coordonnées barycentriques. La moitié des points tombe dans le quart central du triangle (mesuré) : un amas au milieu.

Schéma 3 · Le reste de la division

Quand la plage ne se divise pas

Ramener un entier aléatoire dans 0 à n − 1 par le reste de la division est le réflexe de tout programmeur. Il est juste seulement si n divise le nombre de valeurs possibles.

Exemple autonome · C#, réduire sans biais, par rejetint limite = 256 - 256 % n; // 200 pour n = 100 int x; do x = octet(); while (x >= limite); // rejeter la tranche incomplète return x % n;

La version flottante

(int)(NextDouble() * n) a le même défaut, bien plus discret : les doubles de [0, 1) ne se répartissent pas exactement en n paquets égaux, sauf pour n puissance de deux.

Ce qu'il faut retenir

Pour un indice, Next(n) ; pour un intervalle, Next(a, b) avec b exclu ; pour un réel, NextDouble. N'écris le calcul toi-même que si tu sais compter ses chemins.

Piège courant Tirer un pourcentage par octet % 100. Les valeurs 0 à 55 sont sorties 1,171 % du temps chacune, les autres 0,782 % : moitié plus souvent (mesuré).

Glossaire

Biais
Un écart systématique entre les fréquences obtenues et celles attendues.
Borne exclusive
Une limite qui n'est jamais atteinte par le tirage.
Fisher-Yates
Le mélange qui échange chaque case avec une case non encore fixée.
Échantillonnage par rejet
Tirer large et jeter ce qui sort du domaine voulu.
Biais du modulo
L'inégalité créée par un reste quand n ne divise pas la plage.
