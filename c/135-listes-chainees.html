Le concept

Les listes chaînées

Au lieu d'un bloc de cases voisines, une liste chaînée range chaque élément dans son propre nœud, qui désigne le suivant. Insérer n'importe où devient gratuit, mais trouver devient long, et la mémoire s'éparpille. Le vrai usage du chaînage est ailleurs : chaque fois qu'un objet désigne son parent.

45 min de lecture et de QCM Prérequis · 92, 133 Exemples · SnapSet

L'idée en une phrase

Une chaîne échange l'accès direct contre l'insertion gratuite ; elle ne gagne que si l'on tient déjà le nœud où agir.

L'analogie

Un jeu de piste : chaque indice dit où trouver le suivant. Ajouter une étape est facile ; aller directement à la dixième est impossible.

À la fin, tu sais

  1. dire quand une chaîne gagne ;
  2. mesurer le coût des sauts ;
  3. remonter une chaîne de parents ;
  4. détecter une boucle.
À retenir Par défaut, une List. Une LinkedList seulement avec un accès direct aux nœuds, comme dans un cache LRU. Une chaîne de parents est une liste chaînée : ses règles s'appliquent.

Schéma 1 · Insérer sans décaler

Gratuit, à condition de tenir le nœud

Insérer dans une chaîne, c'est changer deux liens. Mais pour savoir quels liens changer, il faut d'abord arriver au bon endroit. On a mesuré les deux moitiés du travail.

Exemple autonome · C#, un cache LRU : le dictionnaire trouve, la chaîne ordonneif (index.TryGetValue(cle, out var noeud)) { ordre.Remove(noeud); ordre.AddFirst(noeud); return noeud.Value; } if (index.Count == capacite) { index.Remove(ordre.Last.Value.Cle); ordre.RemoveLast(); } index[cle] = ordre.AddFirst(Calculer(cle));

Le cas où la chaîne gagne

Un cache LRU déplace l'élément lu en tête et retire le plus ancien en queue, à chaque accès. Le dictionnaire donne le nœud, la chaîne le déplace sans rien décaler : 167 ns par accès (mesuré).

Le nœud est un objet

AddAfter rend le nœud créé ; Remove(nœud) le retire en un pas. Remove(valeur), lui, cherche d'abord : c'est un Find caché.

Piège courant Choisir LinkedList « parce qu'on insère au milieu », puis chercher le milieu à chaque fois. La recherche coûte plus que le décalage qu'on voulait éviter.

Schéma 2 · Le prix des pointeurs

Six fois la mémoire, et des sauts

Un entier dans une liste coûte 4 octets ; dans une chaîne, un nœud entier. Et parcourir une chaîne, c'est suivre des adresses, que le processeur ne peut pas toujours deviner.

Exemple autonome · C#, ce qu'un nœud transportepublic sealed class LinkedListNode<T> // simplifié { internal LinkedList<T> list; internal LinkedListNode<T> next, prev; internal T item; }

D'où viennent les 48 octets

L'en-tête de l'objet (16 octets), trois références de 8 octets, et l'entier arrondi à 8. Pour 4 octets utiles, douze fois plus d'emballage (déduit du relevé).

Les caches du processeur

Un tableau se lit par lignes de cache entières : un accès en amène seize. Une chaîne en désordre paie un aller-retour vers la mémoire à chaque nœud (cours 92).

Piège courant Juger une chaîne sur un essai tout neuf. Créés à la suite, les nœuds se parcourent en 10 ms ; reliés dans le désordre, il en faut 136 à 162 pour le même million (mesuré).

Schéma 3 · Une chaîne qui monte

Remonter les parents

Chercher la racine, un ancêtre verrouillé, un ancêtre sélectionné : c'est parcourir une chaîne, de lien en lien. Deux façons de ranger ces liens, et une façon de survivre à une boucle.

Exemple autonome · C#, détecter une boucle sans compteur arbitraireGuid lent = id, vite = id; while (parent.TryGetValue(vite, out vite) && parent.TryGetValue(vite, out vite)) { parent.TryGetValue(lent, out lent); if (lent == vite) throw new InvalidOperationException("Cycle"); // ils se rejoignent dans la boucle }

Pourquoi un dictionnaire

SnapSet range les parents dans un Dictionary<Guid, Guid> à part : l'arbre se recopie, se fige pendant un geste et se compare, sans toucher aux objets du document.

Le compteur de garde

Arrêter après N pas protège d'une boucle infinie, mais N est arbitraire : trop petit, il coupe un arbre légitime ; grand, il fait attendre avant d'échouer.

Piège courant Remonter une chaîne de parents sans aucune protection, en comptant sur « impossible par construction ». Un fichier abîmé ou un collage suffit à rendre la boucle possible.

Glossaire

Liste chaînée
Une suite de nœuds où chacun désigne le suivant, et ici aussi le précédent.
Nœud
Le petit objet qui porte une valeur et ses liens.
Cache LRU
Un cache qui jette l'élément utilisé il y a le plus longtemps.
Localité
Le fait que les données lues à la suite soient voisines en mémoire.
Algorithme de Floyd
La détection d'une boucle par deux curseurs de vitesses différentes.
