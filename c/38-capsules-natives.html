Le concept

Des capsules natives dans le navigateur

Sur le canvas web de Magpie, un composant Grasshopper a exactement l'allure qu'il a dans Grasshopper. Le web ne le redessine pas : il affiche une image que Grasshopper a peinte lui-même, et pose dessus des poignées invisibles aux coordonnées que Grasshopper a mesurées.

50 min de lecture et de QCM Prérequis · 19, 20, 31 et 32 Exemples · outils/export-capsules.cs, src/data/capsules.json, src/GenericNode.jsx (Magpie web)

L'idée en une phrase

Une fois pour toutes, un script lancé dans Rhino fait peindre à Grasshopper chaque composant du catalogue dans une image, et note où sont ses poignées ; le navigateur n'a plus qu'à afficher l'image et à accrocher les fils aux bons endroits.

L'analogie

Un décor de théâtre photographié plutôt que repeint : la photo est fidèle au détail près, et un plan indique où sont les portes par lesquelles les acteurs entrent et sortent.

À la fin, tu sais

  1. suivre le rendu d'une capsule dans export-capsules.cs ;
  2. lire une entrée de capsules.json ;
  3. dire comment GenericNode pose les poignées sur l'image ;
  4. choisir entre éditeur HTML, image et capsule compacte.
À retenir 724 capsules pour 727 composants au catalogue. Les trois absents sont des échecs attendus (lignes 12–13) : Group n'est pas un composant posable, Digit Scroller et Cherry Picker sont des contrôles interactifs. Number Slider, Boolean Toggle et Panel, qu'on manipule, sont dessinés en HTML.

Schéma 1 · Faire peindre Grasshopper

Un document par composant, une image par document

Le script lit les typeGuid du catalogue web, puis, pour chacun, crée le composant, le pose seul dans un document neuf, mesure son cadre, et demande au canvas de Grasshopper une image haute résolution de ce cadre.

outils/export-capsules.cs · 76–82var vp = Activator.CreateInstance(vpType); set(vp, "Width", (int)Math.Ceiling((b.Width + 2 * margin) * zoom)); set(vp, "Height", (int)Math.Ceiling((b.Height + 2 * margin) * zoom)); set(vp, "Zoom", zoom); set(vp, "MidPoint", new System.Drawing.PointF(b.X + b.Width / 2, b.Y + b.Height / 2)); using (var bmp = (System.Drawing.Bitmap)canvasType.GetMethod("GenerateHiResImageTile") .Invoke(canvas, new object[] { vp, System.Drawing.Color.Transparent })) bmp.Save(imgDir + guid + ".png", System.Drawing.Imaging.ImageFormat.Png);

Tout par réflexion

Le script s'exécute dans Rhino 8, par le MCP Rhino (execute_rhinocommon_csharp_code). Ce contexte ne référence pas Grasshopper : le script retrouve l'assembly chargée (ligne 15), puis chaque type, propriété et méthode par son nom (cours 27).

Un état neutre, figé

Le canvas calcule ce qu'il dessine. Une entrée obligatoire vide teinterait la capsule en orange, et ce serait dans l'image pour toujours. Les entrées passent donc facultatives (lignes 45–57), le document est désactivé et les messages effacés (70–75).

Piège courant Ajouter un composant au catalogue sans relancer l'export (ligne 9 : « À relancer quand le catalogue change »). Il n'a pas d'entrée dans capsules.json : le web le dessine alors en capsule compacte, sans erreur, et la différence passe inaperçue.

Schéma 2 · La taille et les poignées

Des unités Grasshopper, depuis le coin de l'image

Pour chaque composant, capsules.json donne la taille de l'image et la position de chaque poignée. Les nombres sont en unités du canvas Grasshopper au zoom 1, comptés depuis le coin haut-gauche de l'image, marge comprise.

src/data/capsules.json · 2"323f3245-af49-4489-8677-7a2c73664077": { "width": 77, "height": 56, "inputs": [{ "name": "Curve", "x": 8, "y": 28 }], "outputs": [{ "name": "Closed", "x": 69, "y": 18 }, { "name": "Periodic", "x": 69, "y": 38 }] },

Trois fois plus de pixels

L'image est peinte au zoom 3 (ligne 24) : 231 × 168 pixels pour une capsule de 77 × 56. Le web l'affiche à 77 × 56 ; quand on zoome le canvas, il reste deux pixels en réserve sur trois, et le dessin reste net.

Compter depuis l'image

Grasshopper donne la poignée en coordonnées du canvas. Le script retire le coin du cadre et ajoute la marge (ligne 88) : x = poignée.X − cadre.X + 6. La largeur, elle, vaut le cadre plus deux marges (ligne 110).

Piège courant Régénérer les images sans le JSON, ou l'inverse. Les poignées web sont invisibles (styles.css, lignes 869–878) : si les deux fichiers ne viennent pas du même export, les fils s'accrochent à côté des poignées dessinées, et rien ne le signale. Le script écrit toujours les deux ensemble.

Schéma 3 · Trois façons de dessiner un nœud

Éditeur, image ou capsule compacte

GenericNode choisit, pour chaque nœud du graphe, comment le dessiner. Ce qui se manipule est en HTML ; ce qui est figé et a une capsule s'affiche en image ; le reste prend une capsule compacte.

src/styles.css · 887–902, extraits.magpie-capsule-tint { position: absolute; inset: 0; mask-size: 100% 100%; mix-blend-mode: multiply; } .magpie-capsule.is-warning .magpie-capsule-tint { background: #f2a33a; } .magpie-capsule.is-error .magpie-capsule-tint { background: #e0503e; }

L'image sert de masque

Pour teinter une capsule en orange ou en rouge, GenericNode pose une couche de couleur dont le masque est la même image (ligne 127). La couleur ne couvre que la forme du composant, pas le rectangle, et multiply la mêle au dessin.

Le vert de la sélection

Grasshopper teinte en vert un composant sélectionné. Le web dessine un contour vert qui épouse l'image : quatre drop-shadow décalés, sans flou (styles.css, 862–867). Aperçu coupé : l'image est assombrie (brightness(0.72)).

Piège courant Chercher la capsule d'un composant fourni par l'exercice et conservé tel quel (un objet opaque). GenericNode l'écarte exprès (!catalogEntry.isOpaque, ligne 104) : il prend la capsule compacte en pointillés, pour dire « câblable, mais pas modifiable ».

Glossaire

Capsule
La forme arrondie d'un composant Grasshopper, avec ses poignées.
Poignée (grip)
Le petit demi-cercle où un fil entre ou sort.
Réflexion
Trouver et appeler types et méthodes par leur nom, à l'exécution.
Masque CSS
Une image dont la transparence découpe ce qu'on voit d'un élément.
Rendu hors écran
Une peinture faite dans une image, sans fenêtre visible.
