Le concept

Charger une application

Avant le premier clic, le navigateur doit recevoir le HTML, puis le JavaScript qu'il nomme, l'analyser et l'exécuter. Trois leviers règlent cette attente : découper ce qu'on envoie, le compresser, et le garder en cache pour la visite suivante.

45 min de lecture et de QCM Prérequis · 118, 121 Exemples · Magpie web, Vite, compute-proxy

L'idée en une phrase

N'envoyer d'abord que ce qui sert à l'écran d'ouverture, l'envoyer compressé, et ne plus jamais renvoyer un fichier qui n'a pas changé.

L'analogie

Livrer un chantier. On apporte d'abord ce qui sert au premier jour, en palettes serrées ; les outils déjà sur place ne repartent pas au dépôt chaque soir.

À la fin, tu sais

  1. lire une cascade de chargement ;
  2. découper avec import() ;
  3. régler Cache-Control ;
  4. vérifier ce qui part vraiment.
À retenir Le premier chargement se paie en octets et en temps d'exécution ; les suivants ne devraient presque rien coûter. Mesurer les deux, sur un réseau limité, et jamais sur son seul poste de développement.

Schéma 1 · Le poids

Découper et compresser

Vite rassemble le code en paquets. Un import() dynamique en crée un à part, téléchargé quand on l'appelle. On a construit Magpie web et pesé ce qui en sort.

Exemple autonome · JavaScript, charger un module à la demandebouton.addEventListener("click", async () => { const { ouvrirExport } = await import("./export.js"); // paquet à part ouvrirExport(); });

Avec React

lazy(() => import("./Viewer3D.jsx")) et un Suspense autour : React affiche le repli le temps que le paquet arrive. C'est ce que fait App.jsx:18.

Compresser

C'est le serveur qui compresse, en gzip ou en brotli, si le navigateur l'annonce. Le JavaScript, très répétitif, s'y prête bien : trois fois moins ici, selon Vite.

Piège courant Importer un gros fichier de données en tête d'un module. Il entre dans le paquet principal et se télécharge avant tout affichage : capsules.json pèse 130 Ko du paquet de Magpie (GenericNode.jsx:8).

Schéma 2 · Le cache HTTP

Ne rien renvoyer deux fois

L'en-tête Cache-Control dit au navigateur combien de temps garder un fichier. Vite met une empreinte du contenu dans le nom de chaque paquet : un nom ne désigne donc qu'un seul contenu, pour toujours.

Exemple autonome · Node, permettre la réponse 304const etag = `"${stat.size}-${stat.mtimeMs}"`; if (req.headers["if-none-match"] === etag) { res.writeHead(304); return res.end(); // rien à renvoyer } res.writeHead(200, { ETag: etag, "Cache-Control": "no-cache" });

Deux régimes

Les fichiers à empreinte : max-age=31536000, immutable, gardés un an sans question. Le reste : no-cache, gardé mais vérifié auprès du serveur avant usage.

Pourquoi pas tout

index.html nomme les paquets du jour. Gardé sans vérifier, il réclamerait après une mise en ligne des fichiers qui n'existent plus. C'est la seule porte d'entrée à revérifier.

Piège courant Mettre une longue durée de cache sur un fichier sans empreinte, comme app.js ou logo.png. Après une correction, une partie des visiteurs garde l'ancienne version, et rien ne permet de la leur retirer.

Schéma 3 · Ce qui part vraiment

Un paquet à part n'est pas un paquet évité

Le paquet de la 3D est séparé. Mais il se télécharge dès que le composant s'affiche, et Magpie ouvre l'aperçu d'office sur un écran large. On a comparé deux largeurs de fenêtre.

Exemple autonome · JSX, anticiper sans imposer// le module, une fois reçu, est gardé : le second import() ne coûte rien const charger = () => import("./Viewer3D.jsx"); <button onPointerEnter={charger} onClick={ouvrir}>Aperçu 3D</button>

Le service worker

Il intercepte les requêtes de la page et peut répondre depuis la Cache API, même hors ligne. Magpie a un manifeste pour s'installer, mais aucun service worker (recherche dans src/).

Mesurer soi-même

L'onglet Network des DevTools, cache désactivé et débit limité, donne la même cascade que page 1. C'est l'objet du cours 126.

Piège courant Juger le chargement sur localhost. Le réseau y est instantané et le cache déjà plein : la seconde visite a affiché le canvas en 291 ms, la première en 666 ms, à seulement 10 Mbit/s.

Glossaire

Paquet (bundle)
Un fichier JavaScript qui rassemble plusieurs modules.
Découpage
La séparation du code en paquets chargés à la demande.
Empreinte
Un code tiré du contenu, mis dans le nom du fichier.
Revalidation
La question au serveur : ce fichier a-t-il changé ?
Cascade
Le diagramme des requêtes d'une page dans le temps.
