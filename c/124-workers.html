Le concept

Les workers

Une page n'a qu'un fil principal : il traite les clics, fait tourner React, met en page et peint. Un calcul long l'occupe, et tout se fige. Un worker est un second fil, sans accès à la page, à qui l'on confie ce calcul par messages.

45 min de lecture et de QCM Prérequis · 121, 122 Exemples · Magpie web, aperçu 3D

L'idée en une phrase

Ce qui calcule longtemps sans toucher la page peut partir dans un worker ; on lui envoie les données, il renvoie le résultat, et le fil principal reste disponible entre les deux.

L'analogie

Le comptoir d'un atelier. Le vendeur ne découpe pas les pièces pendant que les clients attendent : il transmet le bon de commande à l'atelier, et sert les suivants.

À la fin, tu sais

  1. mesurer ce qui fige le fil ;
  2. créer un worker et lui parler ;
  3. transférer plutôt que copier ;
  4. savoir quand ça ne vaut pas la peine.
À retenir Un worker n'accélère pas un calcul : il le déplace. On y gagne un fil principal libre ; on y paie un démarrage et le passage des données.

Schéma 1 · Ce qui fige la page

Mesurer avant de déplacer

Le serveur de Magpie plafonne un aperçu 3D à 200 000 triangles et 5 Mio. On a fabriqué un aperçu à ce plafond, et mesuré ce que la page doit en faire avant de l'afficher.

Exemple autonome · JavaScript, un worker qui décode// decode.worker.js onmessage = (e) => { const octets = Uint8Array.from(atob(e.data), (c) => c.charCodeAt(0)); postMessage(octets.buffer, [octets.buffer]); // transfert : aucune copie };

Créer un worker

new Worker(new URL("./decode.worker.js", import.meta.url), { type: "module" }) : écrit ainsi, Vite reconnaît le fichier et l'empaquette à part.

Ce qu'il n'a pas

Ni document, ni window, ni état React. Il a fetch, atob, les minuteries, WebAssembly, et OffscreenCanvas pour dessiner hors de la page.

Piège courant Envoyer au worker un calcul d'une milliseconde. Rien que son démarrage a pris 14,4 ms (mesuré), et chaque message copie ses données : le worker coûte alors plus qu'il ne libère.

Schéma 2 · Le passage des données

Copier ou transférer

Un message est copié par défaut. Pour un tampon binaire, on peut le donner au lieu de le copier : il change de fil, et l'émetteur le perd. On a mesuré les deux sur 5 Mio.

Exemple autonome · JavaScript, transférer un tamponconst positions = new Float32Array(3 * nbSommets); worker.postMessage(positions.buffer, [positions.buffer]); // la liste nomme ce qui est transféré console.log(positions.length); // 0 : le tableau est désormais vide

Ce qui se transfère

Les ArrayBuffer, les MessagePort, les ImageBitmap, les OffscreenCanvas. Les chaînes et les objets ordinaires se copient toujours : les 7 Mo de base64 envoyés au worker l'ont été.

Partager

Un SharedArrayBuffer est lu par les deux fils à la fois. Il exige une page isolée, servie avec les en-têtes COOP et COEP ; sans eux, il n'existe pas (mesuré).

Piège courant Relire un tableau après avoir transféré son tampon. Il ne lève pas toujours d'erreur : sa longueur vaut 0, une boucle ne fait rien, et le dessin reste vide sans raison apparente.

Schéma 3 · Libérer n'est pas accélérer

Ce que voit le fil principal

Le même décodage, fait sur place puis dans un worker. Pendant ce temps, une minuterie de 10 ms mesure si le fil principal répond encore.

Exemple autonome · JavaScript, une promesse autour du workerfunction decoderAilleurs(worker, texte) { return new Promise((ok) => { worker.onmessage = (e) => ok(new Float32Array(e.data)); worker.postMessage(texte); }); }

Combien de workers

Pas plus que de cœurs : navigator.hardwareConcurrency en donne le nombre. Un worker gardé ouvert sert plusieurs fois ; terminate() le libère.

Le service worker

Malgré le nom, ce n'est pas un fil de calcul : il s'interpose entre la page et le réseau, pour le cache et le hors-ligne. C'est un sujet du cours 125.

Piège courant Mesurer le worker au chronomètre global. L'aller-retour a pris plus longtemps que le calcul sur place ; le gain se lit ailleurs, dans les clics et les images qui passent pendant ce temps.

Glossaire

Fil
Une suite d'instructions exécutée à son rythme ; la page en a un principal.
Worker
Un fil de calcul sans accès à la page, qui parle par messages.
Clonage structuré
La copie que fait postMessage d'un objet envoyé.
Transfert
Le passage d'un tampon à l'autre fil, sans copie ; l'émetteur le perd.
Isolation d'origine
Un mode de page, obtenu par en-têtes, qui ouvre SharedArrayBuffer.
