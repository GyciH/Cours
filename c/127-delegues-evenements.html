Le concept

Délégués et événements

Un délégué est une méthode rangée dans une variable : on peut la passer, la garder, l'appeler plus tard. Un événement est une liste de délégués qu'un objet appelle quand quelque chose arrive. Grasshopper prévient ainsi SnapSet d'un clic ou d'un ajout, et c'est aussi par là que fuit la mémoire.

45 min de lecture et de QCM Prérequis · 01, 58 Exemples · SnapSet, Conception

L'idée en une phrase

Celui qui publie un événement garde une référence vers chacun de ses abonnés ; tout abonnement doit donc avoir sa fin, prévue dès qu'on l'écrit.

L'analogie

Une liste de diffusion. S'y inscrire est facile ; mais tant qu'on n'est pas désinscrit, on reçoit le courrier, même après avoir déménagé, et la liste garde l'adresse.

À la fin, tu sais

  1. dire qui retient qui ;
  2. se désabonner pour de bon ;
  3. choisir une table faible ;
  4. prévoir l'erreur d'un abonné.
À retenir Un abonné à courte vie sur un éditeur à longue vie, c'est une fuite tant qu'il ne se désabonne pas. L'inverse ne pose pas de problème : l'éditeur part avec ses abonnements.

Schéma 1 · Qui retient qui

L'abonnement qui garde en vie

On a abonné mille objets à un événement statique, comme RhinoApp.Idle, puis on les a oubliés. Puis on a rangé cent documents comme clés, dans un dictionnaire et dans une table faible.

Exemple autonome · C#, un abonnement qui a sa finsealed class Apercu : IDisposable { public Apercu() { RhinoApp.Idle += SurRepos; } public void Dispose() { RhinoApp.Idle -= SurRepos; } // même méthode, même cible : retiré void SurRepos(object s, EventArgs e) { /* … */ } }

Statique, donc éternel

RhinoApp.Idle, un champ static : ils vivent jusqu'à la fermeture de Rhino. Tout objet qu'ils pointent aussi, quelle que soit la fenêtre qu'on a fermée.

La table faible

ConditionalWeakTable attache une valeur à un objet sans le retenir : la paire disparaît avec la clé. RegistreDocument.cs:36 s'en sert pour un registre par document.

Piège courant S'abonner à un événement statique depuis le constructeur d'un composant. Supprimé du canvas, le composant reste en mémoire, et son gestionnaire continue d'être appelé à chaque repos de Rhino.

Schéma 2 · Se désabonner

Retirer le bon délégué

-= ne retire un gestionnaire que s'il retrouve un délégué égal : même méthode, même cible. On a essayé trois écritures courantes.

Exemple autonome · C#, s'abonner une seule fois par objetreadonly HashSet<Champ> _suivis = new HashSet<Champ>(); void Suivre(Champ c) { if (!_suivis.Add(c)) return; // déjà abonné : on ne double pas c.MesureChangee += (s, e) => Redessiner(); }

Une fois par objet

S'abonner deux fois, c'est être appelé deux fois. CapsuleExecution.cs:397 garde la liste des constituants déjà suivis et sort tout de suite s'il le connaît.

En miroir

ServiceGeste.cs branche huit événements du canvas (lignes 40 à 47) et les retire tous, dans le même ordre, quand le canvas disparaît (lignes 266 à 273).

Piège courant Écrire la même lambda dans le += et dans le -=. Le compilateur en fait deux délégués : le -= ne trouve rien, ne dit rien, et le gestionnaire reste branché.

Schéma 3 · L'ordre, l'erreur, le coût

Ce qui se passe au déclenchement

Un événement appelle ses abonnés un par un, dans l'ordre d'abonnement, sur le fil qui le déclenche. Si l'un échoue, la suite n'a pas lieu. On a mesuré l'ordre, l'erreur et le prix.

Exemple autonome · C#, déclarer et déclencherpublic event EventHandler MesureChangee; protected void SignalerMesure() => MesureChangee?.Invoke(this, EventArgs.Empty); // ?. lit la liste une fois : un abonné qui se retire pendant l'appel ne la casse pas

Action, Func, EventHandler

Action ne rend rien, Func rend une valeur, EventHandler reçoit l'émetteur et des arguments. CapsuleExecution expose un simple Action, QuandMesureChange (ligne 130).

Le fil du déclencheur

Un gestionnaire tourne sur le fil qui déclenche. Un événement levé hors du fil de l'interface ne doit pas toucher un contrôle : on repasse par BeginInvoke (cours 44).

Piège courant Laisser un gestionnaire lever une exception. Elle remonte chez celui qui a déclenché l'événement, et les abonnés suivants ne sont jamais appelés : un greffon peut en priver un autre.

Glossaire

Délégué
Une référence vers une méthode, et vers l'objet qui la porte.
Événement
Une liste de délégués qu'un objet appelle quand quelque chose arrive.
Abonné
L'objet dont une méthode est dans la liste.
Délégué multicast
Un délégué qui en appelle plusieurs, dans l'ordre.
Référence faible
Une référence qui n'empêche pas le ramasse-miettes de libérer l'objet.
